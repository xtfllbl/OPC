# 0001. OPC_ATTD 模块化自包含架构设计

在 Paywizard 原型仓库中，`1.unified_pos.html` 逐渐膨胀为包含收银台、批报表、系统设置、数字键盘的 6200+ 行单体文件，维护风险高且容易引发冲突。

我们决定在子目录 `OPC_ATTD/` 中建立一个自包含的 Attended POS 子项目：核心收银主屏保持单页交互体验并分离 CSS/JS 模块，将只读管理性质的批结算报表独立为 `batch_reports.html`，并将关联的收银闭环文件（小费、双通道退款、小票、交易记录）及所需资源安全复制进该目录并规范化命名。

这样既消除了在数千行单文件中维护的脆弱性，又避免了全页面跳转重载对终端操作流畅度的破坏，同时保证根目录现有原型不受任何影响。
