# Tip Adjust 分离保存与执行

为支持收银员先连续录入小费、再核对并统一执行，Tip Adjust 将 SAVE 定义为保存待执行值，界面继续使用 ADJUSTED 表示已保存，而不是渠道执行成功；执行成功的交易退出该模块的工作列表，原交易记录与报表仍保留。执行前的保存值与已生效金额分开，避免待执行值提前影响交易和批次财务金额。

独立 Close Batch 在提示待执行笔数及未设置调整金额的笔数后，先自动执行已保存调整，再结算批次，避免要求操作员额外返回 Tip Adjust 手动执行。本轮原型仅模拟成功路径，已在 OPC_ATTD 实施。
